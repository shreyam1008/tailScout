# Contributing to TailScout

TailScout started as a personal project — a clean native GUI for Tailscale that I wanted
on my own Linux machine. It's now public because others might find it useful too.

**Contributions are genuinely welcome** — bug reports, suggestions, fixes, new
features, documentation improvements. No contribution is too small.

## How to contribute

- **Found a bug or have an idea?** [Open an issue](https://github.com/shreyam1008/tailScout/issues).
- **Want to fix or add something?** Open a pull request against `main`.
- **Quick question or suggestion?** An issue is fine for that too.

## Before opening a PR

`cargo fmt`, `cargo clippy`, `cargo test` — all clean. One thing per PR. Follow `AGENTS.md`.

That's it. No CLA, no lengthy process — just a conversation between people who want to make something useful. Think of it less like filing a ticket and more like tapping someone on the shoulder. Say what you found, what you tried, what you think — and we'll figure it out together.
