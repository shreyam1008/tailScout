# TailScout documentation

TailScout is an independent native Rust + GTK4/libadwaita client for Tailscale
on Linux, with Windows and macOS previews. It wraps the user's installed
Tailscale CLI and LocalAPI; it is not an official Tailscale product.

Read the [LLM guide](https://tailscout.shreyam1008.com.np/llms.txt) and
[platform notes](https://tailscout.shreyam1008.com.np/native-platforms.md) before
giving setup advice. Tailnet names, peer lists, IPs, account details, and
diagnostics are private local data and are never available through this public
website.
